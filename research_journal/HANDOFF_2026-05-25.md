## 2. The CRITICAL user feedback that shaped Thatcher v5 (eye-only)

This was discovered iteratively over ~6 versions of the Thatcher
implementation. Key insights:

### Feedback 1: "拼缝还是有点大" (seams too obvious)
**Fix**: replaced convex hull with TIGHT landmark-ordered polygons + Poisson
`seamlessClone` (Pérez 2003). Result: seam invisible in surrounding skin
gradient because Poisson solves Laplace equation matching gradients at
mask boundary.

### Feedback 2: "原来的眼睛/嘴没消除...围绕嘴唇下沿/眼睛上沿翻转"
**Diagnosis**: rotation was around bbox edge (not centroid), so rotated
feature OFFSET from original → ghost of original remained visible.
**Fix**:
- Compute polygon centroid (cx, cy)
- Build CENTROID-SYMMETRIC bbox: dx_max = max(|x - cx|), dy_max = max(|y - cy|)
- Now rotating the bbox patch 180° rotates around the centroid (= polygon center)
- mask_union = mask ∪ rotate_180(mask): covers BOTH original position and
  rotated position. Any wedge missed by the rotated patch still gets
  replaced by the rotated content, eliminating ghosts.

### Feedback 3: "眼袋/下眼睑应该框住" + "眼影/眼妆应该一起框住"
**Fix**: in `precise_polygons.eye_brow_polygon` and `eye_only_polygon`:
- pad lower eye landmarks DOWN by 13% IOD (eye bags)
- pad ALL points outward from polygon centroid by 7% IOD (lateral makeup)

### Feedback 4: "眉毛必须很浅，否则很容易看出和眼睛之间的关系" → STRICT brow filter
**Then SUPERSEDED**: user discovered an even better fix.

### Feedback 5 (THE BREAKTHROUGH): "如果我们只转眼睛不转眉毛，效果会好很多"
This is the **Thompson 1980 canonical** approach. Don't rotate brows at all
— only rotate the EYE region (iris + lashes + lids, but NOT brow) and
mouth. Brows stay anchored, making the face "look almost normal at first
glance" — exactly Thompson's perceptual signature.

**Implementation**: replaced `eye_brow_polygon` with `eye_only_polygon`
in `thatcher_classical.py` polygon list. brow_subtle filter became
unnecessary (set default to 1000 = effectively disabled).

### Feedback 6: "在野表情才是 illusion 创造的核心内容"
**Decision**: ALLOW smiling / wild-expression faces (FFHQ is in-the-wild,
not lab-controlled). Filter `mouth_open_frac ≤ 0.18` rejects only
LOUDLY-laughing / yawning faces. Mild smiles pass. This means V2's
smile-flipped-to-frown is sometimes more dramatic than Thompson's neutral
originals — accept this per user's ecological validity preference.

### Feedback 7: "能加速吗?"
**Fix**: dlib is single-threaded; box has 224 cores. Wrote
`thatcher_parallel.py` using `multiprocessing.Pool(64)`. Each worker:
- Has its own dlib detector + predictor instance
- Processes one tar at a time (no cross-process contention)
- Writes to per-identity dir named by ffhq_name (no shared counter race)
- Idempotent: skips dirs with existing `thatcher_V4.png`

Achieved **~21× speedup**: 75.7 min vs projected 26h single-thread.

## 3. The CURRENT working Thatcher algorithm (canonical reference)

This is the **exact pipeline** that produced the released v1.0 dataset.
Replicate this for Composite + Part-Whole.

### 3.1 Source data
- **FFHQ-1024-WDS** (gaunernst/ffhq-1024-wds on HF, 70 tar shards, 70k images)

### 3.2 Face detection + landmarks
- **dlib HOG + SVM** detector (`dlib.get_frontal_face_detector()`)
- **dlib 68-pt shape predictor** (Kazemi & Sullivan 2014)
- Model file: `/workspace/models/shape_predictor_68_face_landmarks.dat` (96 MB, downloaded from `davisking/dlib-models` GitHub)
- Wrapped in `stimuli/classical_cv/face_pipeline.py:FacePipeline`

### 3.3 Filter criteria (`face_pipeline.default_filter`)
```python
{
  "iod_ok":           iod_px >= 120.0,          # min inter-ocular distance
  "tilt_ok":          tilt_deg <= 15.0,         # eye-line tilt from horizontal
  "yaw_ok":           yaw_score <= 0.18,        # ~ < 15° head yaw
  "face_dominant":    face_area_frac >= 0.20,   # bbox area / frame area
  "no_glasses":       glasses_edge_density <= 0.07,  # Canny in eye region
  "mouth_not_wide_open": mouth_open_frac <= 0.18,    # inner-lip / mouth-width
  "brow_subtle":      brow_skin_L_diff <= 1000,      # DISABLED for eye-only
}
```
Pass rate: **37.6% of 70k FFHQ → 26,317 identities**.

### 3.4 Polygon construction (`stimuli/classical_cv/precise_polygons.py`)

#### Eye-only polygon (for Thatcher V2 — the operational polygon)
```python
def eye_only_polygon(landmarks, eye_idx,
                     pad_above=0.05, pad_below=0.10,
                     pad_lateral=0.05, iod=100.0) -> np.ndarray:
  # eye_idx = landmarks 36-41 (LEFT_EYE) or 42-47 (RIGHT_EYE)
  # 1. Pad UPPER eye landmarks UP by 5% IOD (covers eyelid)
  # 2. Pad LOWER eye landmarks DOWN by 10% IOD (covers eye bag)
  # 3. Pad ALL points outward from polygon centroid by 5% IOD (lateral makeup)
  # 4. Return convexHull of the padded points
```

#### Mouth polygon
```python
def mouth_polygon(landmarks, pad_frac=0.07, iod=100.0) -> np.ndarray:
  # landmarks[48:60] = 12 outer-lip points (ordered)
  # Pad each point OUTWARD from centroid by 7% IOD
  # Return as ordered polygon (no hull needed — already convex)
```

### 3.5 Thatcher transform with centroid rotation + ghost-union mask
(`stimuli/classical_cv/thatcher_classical.py:thatcherize_classical`)

For each region (L_eye, R_eye, mouth):
1. Build polygon (above)
2. Compute centroid `(cx, cy)` via `polygon_centroid`
3. Build centroid-symmetric bbox:
   ```python
   dx = max(abs(xs.max() - cx), abs(cx - xs.min())) + pad
   dy = max(abs(ys.max() - cy), abs(cy - ys.min())) + pad
   x1, x2 = cx - dx, cx + dx;  y1, y2 = cy - dy, cy + dy
   ```
4. Extract patch `out[y1:y2, x1:x2]`; rotate 180° via `cv2.rotate(patch, ROTATE_180)`
5. Build mask in bbox-local coords; rotate 180° too; union them
6. `cv2.seamlessClone(patch_rot, out, mask_union, center=(cx,cy), cv2.NORMAL_CLONE)`

Resulting V1=original, V2=thatcherized; V3=rot180(V1), V4=rot180(V2).

**Pixel-baseline ISI = 1.000 by construction** (V3 = rot180(V1), V4 = rot180(V2)
exactly; for any pure-pixel-distance metric `d`, `d(V1,V2) == d(V3,V4)`).

### 3.6 Parallel execution (`stimuli/classical_cv/thatcher_parallel.py`)
- `multiprocessing.Pool(processes=64, initializer=_init)`
- Each worker calls `_init(predictor_path, args_dict)` once → loads dlib
- `pool.imap_unordered(_process_tar, tar_paths)`
- Each task: process one tar, return summary dict
- Per-identity dir name: `ffhq_{ffhq_basename}` (e.g., `ffhq_01234`)
- Idempotent skip: if `ffhq_NAME/thatcher_V4.png` exists, skip

### 6.2 Composite algorithm (Young 1987)
```
For each (i, j) paired identity (within-cluster):
  1. dlib landmarks for both
  2. Rigid affine align j → i's frame using eye centers (similarity transform)
  3. Reinhard LAB color transfer: j_aligned → match i's cheek skin tone
     (sample from cheek annulus via cheek_skin_mask)
  4. Cut at i's nose-tip y (landmark 30)
  5. V1 aligned_same  = top(i) + bot(i), no shift, no swap
  6. V2 aligned_diff  = top(i) + bot(j_recolored), no shift  ← seamlessClone seam
  7. V3 misaligned_same = top(i) + bot(i), shift bottom +60 px (Young's spec)
  8. V4 misaligned_diff = top(i) + bot(j_recolored), shift +60 px
```
Use `cv2.seamlessClone(NORMAL_CLONE)` on a THIN HORIZONTAL STRIP centered on
the cut line, NOT on the whole bottom half (that approach in current
`composite_classical.py` may over-smooth the misalignment signal — please
verify visually and iterate).

**Pixel-baseline CSI** ≈ 1.10 (V1↔V2 differs by bottom swap; V3↔V4 same
swap but shifted — small pixel-asymmetry). Computed in
`analysis/compute_metrics.py` and pixel-corrected.

### 6.3 Part-Whole algorithm (Tanaka & Sengco 1997)
```
For each (i, j) paired (within-cluster):
  1. Build COMBINED eye region polygon (both eyes + brows together,
     since target/foil swap is the WHOLE eye area)
  2. Rigid affine align j to i (same as composite)
  3. Sample skin annulus around eye region from i, use as Reinhard
     reference for j_aligned's color
  4. V1 whole_target = rgb_i (original)
  5. V2 whole_foil   = i with j's eye region pasted via
     cv2.seamlessClone(NORMAL_CLONE)
  6. V3 part_target  = i's eye region on neutral 128-gray canvas
                       (use soft alpha to fade the polygon edge)
  7. V4 part_foil    = j's eye region (color-matched) on the SAME gray
                       canvas at the SAME bbox position
```
**Critical**: V3 and V4 must be on canvases with **IDENTICAL gray background +
SAME bbox position**, otherwise V3↔V4 pixel difference is dominated by
canvas placement noise rather than the eye-content difference.

**Pixel-baseline PWI** ≈ 1.20 (gray canvas V3/V4 share more pixels than
faces V1/V2). Computed in `analysis/compute_metrics.py`.

**§6 PWI threshold direction**: per `project_classical_cv_pivot` memory,
the Tanaka direction is **PWI > 1 = holistic**. Previous benchmark had this
backwards. See `analysis/section6_verdict.py` for the corrected LEGACY +
TANAKA_ALIGNED dual-regime evaluator.
