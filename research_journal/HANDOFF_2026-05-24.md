## 4. THE PROBLEM (just-surfaced by user)

After 30+ ticks of iteration, ISI on Thatcher caps at ~1.0 — the model
NEVER processes Thatcher in the pro-Thatcher direction. Compare to:
- CLIP family: 4-7 on the same stimuli
- DINOv2 frozen: 0.908 (anti-Thatcher)
- Best HOLO-Net iteration: 1.082 (Gen 1 v2.4a α=2.0, but with PWI fail)
- Gen 3 from-scratch: 0.943-0.955

User's hypothesis (in last message before this handoff request):
> "我觉得现在的训练结果有很大问题：4 的 ISI 指标只到了 1，我觉得这一
> 定是架构出问题了。请你重新思考架构问题：还有一种可能是 benchmark 出
> 问题了：Illusion Bench 的设计并不科学严谨。"

**Two diagnostic explanations** (not mutually exclusive):
- **A — Architectural**: SSL contrastive loss internally prefers
  view-invariance; orient-aux at CLS-level can't produce per-patch
  orientation-asymmetric features needed for Psalta 2014's Thatcher
  mechanism.
- **B — Benchmark**: My hand-coded stimuli have artifacts (rotation seams,
  skin-tone mismatch between composite halves, etc.) that CLIP picks up
  via shortcut features rather than via genuine holistic processing.
  The §6 thresholds (ISI ≥ 3.0) were back-derived from what CLIP achieves
  on MY stimuli — not human-anchored.

**If B is true** (which the user suspects), my entire 9-day iteration has
been chasing the wrong target. The stimuli may need to be replaced.

### Specific stimuli concerns (previous agent's audit)

| Paradigm | My implementation | Canonical psych | Risk |
|---|---|---|---|
| Thatcher | MediaPipe FaceMesh → bbox per part → 180° rotate region in PIL | Thompson 1980: hand-cut features, smooth rotation, no seams | Bbox edges + rotation create artifact seams |
| Composite | Top-half ID i + bottom-half ID j; optional misalign | Young 1987: standardized cut + matched lighting/skin | Skin-tone mismatch between halves, model may detect this not configural |
| Part-Whole | Paste donor eye+brow into host face context | Tanaka 1997: show whole, then test isolated parts on gray | Different paradigm entirely (paste vs isolate) |
